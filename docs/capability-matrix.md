# Open CRM Capability Matrix

Last reconciled: 2026-07-23

This is the canonical current-status view. `docs/professionalization-roadmap.md` remains the historical plan and implementation log; executable behavior and this matrix take precedence when its prose has drifted.

Phase 3 decisions, credentials, and operator-owned evidence that cannot be completed through repository changes alone are centralized in `docs/phase-3-decision-register.md`.

## Maturity definitions

| State | Meaning |
| --- | --- |
| `not started` | No meaningful executable product path exists. |
| `schema/API foundation` | Some persistence, service, API, or UI exists, but the promised user outcome is incomplete. |
| `usable with fake provider` | The workflow is demonstrable end to end only through an in-process fake or manual substitute. |
| `production-capable` | The local product path, failure behavior, permissions, and tests are implemented without relying on a fake external effect. Provider-backed features still need real-provider validation. |
| `validated with a real provider/pilot` | Current evidence proves the production path against a real provider or pilot workflow. |

No capability is promoted merely because a migration, definition editor, fake provider, or unit test exists.
